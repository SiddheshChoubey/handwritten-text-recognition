Usage:


python handwritten_scanner_ocr.py input.png
-Scans the image, enhances the handwriting, and extracts text using OCR.

python handwritten_scanner_ocr.py input.png --engine auto
-Automatically selects the available OCR engine to recognize handwriting.

python handwritten_scanner_ocr.py input.png --remove-lines --debug
-Removes notebook lines and saves intermediate images for debugging.

python handwritten_scanner_ocr.py input.png --summarize --num-sentences 3
-Extracts handwritten text and generates a summary containing 3 sentences.
